# Drum samples

The acoustic drum recordings in this folder come from **Big Rusty Drums** by
[Karoryfer Samples](https://karoryfer.com), released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public domain dedication).
Source: https://github.com/sfzinstruments/karoryfer.big-rusty-drums

Each file is a stereo mix of the close and overhead microphones (3 velocity layers × 2
round-robin takes per articulation), trimmed and normalised by `Tools/drums/build_drums.py`.
Thanks to Karoryfer Samples!
